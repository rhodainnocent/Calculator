# Python Simple Calculator

A beginner-friendly calculator built with Python in Jupyter Notebook. This project performs basic arithmetic operations and was created to practice Python fundamentals such as variables, user input, conditional statements, functions, error handling, and object-oriented programming.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Handles invalid operation selection
* Prevents division by zero

## Technologies Used

* Python 3
* Jupyter Notebook
